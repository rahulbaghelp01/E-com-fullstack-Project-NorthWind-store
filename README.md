# NorthWind Store

A full-stack e-commerce application built with React, TypeScript, Node.js, and PostgreSQL.

I followed a tutorial to learn how these technologies work together and how to implement features commonly used in production-style applications.

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** PostgreSQL, Drizzle ORM
- **Authentication:** Clerk
- **Payments:** Polar
- **Chat & Video:** Stream
- **Monitoring:** Sentry
- **Media:** ImageKit

## Features

- User authentication and authorization
- Product browsing and checkout
- Payment processing and webhook handling
- Order management
- Order-related chat and video invitations
- Error monitoring and logging

## What I Learned

- Full-stack application architecture
- REST API development and integration
- Database design and ORM usage
- Authentication and authorization
- Payment workflows and webhooks
- Third-party service integration
